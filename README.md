# podatek-katastralny.pl

Kod i dane serwisu [podatek-katastralny.pl](https://podatek-katastralny.pl): stan prac nad podatkiem katastralnym w Polsce, kalkulator i porównanie z Europą.

## Status licencyjny

Repozytorium jest publiczne dla przejrzystości: każdy może sprawdzić źródła, historię zmian w danych, zasady pobierania nagłówków i sposób liczenia.

Publiczność repozytorium nie oznacza licencji. Zasady ponownego użycia kodu i własnych zbiorów danych serwisu zostaną określone osobno. Do tego czasu obowiązują wszelkie prawa zastrzeżone.

Dane zewnętrzne (OECD, Natural Earth, Sejm RP, Monitor Polski, nagłówki redakcji) podlegają warunkom swoich źródeł. Lista źródeł: [podatek-katastralny.pl/zrodla/](https://podatek-katastralny.pl/zrodla/).
